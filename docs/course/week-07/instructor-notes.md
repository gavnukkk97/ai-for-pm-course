# Н7 · Instructor notes — питч + претест на лендинге Ритма

## Цель демо (~40–45 мин)

Эталон питча + кусок претеста на двух вариантах лендинга/paywall copy Ритма. Полный N=100 можно показать уже готовым логом, live — 4–6 агентов.

---

## Prep

- [ ] 2 варианта текста лендинга Ритма (A/B).  
- [ ] Подвыборка персон P01–P06.  
- [ ] Готовый aggregate отчёт с N=60 (заранее), чтобы не ждать API на занятии.  
- [ ] ЛПР-brief: «CPO маркетплейса привычек, ненавидит vanity metrics».  
- [ ] Слайд границ §3.4.

---

## Скрипт A — Питч (15 мин)

1. Пройти 7 секций эталона.  
2. Underscore слайд «не доказали».  
3. Ask = «бюджет на 2 недели живого теста креатива», не «поверьте симуляции».

## Скрипт B — Претест (15 мин)

1. Protocol на экране.  
2. Live: 2 персоны × variant assignment.  
3. Показать готовый REPORT N=60: effect direction + themes.  
4. Красный флаг: прокрас p-value без оговорок — остановить.

## Скрипт C — ЛПР (10–15 мин)

1. Спарринг на глазах.  
2. Выписать 3 возражения на доску.  
3. Домашка: полный S4 + дек.

---

## Типичные сбои

| Симптом | Реакция |
|---|---|
| N=12 «потому что дорого» | Минимум 50; уменьшить tokens/модель, не N ниже порога без согласования |
| Агент видит оба варианта | Перезапуск; between-subject only |
| Отчёт без validity | Блокер |
| Питч = тур по инструментам Cursor | Вернуть к ставке и ask |
