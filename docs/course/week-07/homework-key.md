## Что выглядит хорошо

| Артефакт | Структура | Quality bar |
|---|---|---|
| Дек | 7±2; секция «не доказали» + ask | Цифры с источниками; ask = живой тест, не «ещё агентов» |
| SPARRING | топ-5 + diff деки | ЛПР возражает; дек реально изменён |
| Protocol | финальный | between-subject; seed; свой artifact |
| REPORT | все 6 блоков | Вердикт согласован с данными; validity честная |
| Логи | assignments + aggregate | Без API keys; N≥50 |

**Отлично:** N 50–100; inconclusive с ясным живым шагом.  
**Достаточно:** N=50, REPORT полный, дек обновлён.  
**Недостаточно:** N=12; ship/kill без оговорок; within-subject.

## Частые провалы

| Симптом | Ремедиация |
|---|---|
| N=12 «дорого» | Дешёвая модель + тот же протокол; цель курса ≥50 |
| p-value без оговорок | Синтетика ≠ живой АБ; вердикт + validity |
| Питч = тур Cursor | Вернуть к 7 секциям стейкхолдера |
| Smoke выдан как S4 | Отклонить |
| Утечка вариантов | Перепроверить assignments |
| Чужой/Ритм артефакт | Только свой продукт |

## Чеклист оценки

### Питч (0–3)
- [ ] 7±2 секции  
- [ ] «не доказали» + ask  
- [ ] SPARRING → дек обновлён  

### S4 (0–5)
- [ ] Protocol between-subject  
- [ ] N≥50  
- [ ] Seed/модель зафиксированы  
- [ ] REPORT полный  
- [ ] Логи без ключей  

**Pass:** питч ≥2 и S4 ≥4.  
**Auto-rework:** ship/kill без validity; N<50; within-subject.
