## Что выглядит хорошо

| Артефакт | Структура | Quality bar |
|---|---|---|
| Ставки | ровно 3; kill + цена ошибки | Связь с H__; контур не «весь ChatGPT» |
| MEMO | go/no-go/thin-bet + «не решили бы» | Хотя бы одна ставка no-go или thin-bet — признак мышления |
| Bottom-up | сегмент→reach→conv→impact | Не top-down TAM «рынок $X млрд» |
| Tornado | ≥3 допущения ±% | Sources; trial/reach часто чувствительнее price |
| Decision memo | stub заполнен | Следующий живой шаг конкретен |

**Отлично:** tornado показывает, что trial важнее price; kill-критерий числовой.  
**Достаточно:** bottom-up с assumption-метками + tornado ×3.  
**Недостаточно:** одно «магическое» число рынка без чувствительности.

## Частые провалы

| Симптом | Ремедиация |
|---|---|
| TAM сверху вниз | «С какого сегмента и reach начнём?» |
| Нет kill-критерия | Добавить: метрика + порог + срок |
| Tornado без source | Метка assumption/desk/live на каждое допущение |
| Все три ставки = go | Спросить цену ошибки; часто thin-bet честнее |
| Ставка «внедрить ChatGPT» | Вернуть к глагол+объект+H__ |
| Копия чисел Ритма | Свои сегменты; эталон только структура |
