# Что дальше после курса · Monday survival

Короткий операционный ритуал **после Н8** (и полезно как еженедельный ритм уже с Н3). Цель — чтобы harness + n8n + SUL-гигиена жили в понедельничной работе, а не только в сдаче.

Связано: [`week-08/`](./week-08/) · [`sul/`](./sul/) · n8n digests [`sul/n8n/`](./sul/n8n/).

---

## Ритуал на 30–45 минут (раз в неделю)

Сделайте **ровно три** пункта — не больше. Если не успели — режьте scope, не пропускайте все три категории.

### 1. n8n digest (≈10–15 мин)

- [ ] Открыть рабочий flow digest (курс: flow #2 сигналы → digest или #3 analytics digest).  
- [ ] Прогнать **один** реальный вход (webhook / ручной trigger) → артефакт на диске или в cloud output.  
- [ ] Прочитать глазами: один факт «агент полезен» / один «агент врёт или шумит».  
- [ ] Нет ключей в git; ротация токенов — вне репо.

Если flow ещё сырой: хватает пустого «heartbeat» workflow + заметка `runs/n8n/monday-YYYYMMDD.md` («что хотел автоматизировать»).

### 2. Один skill (≈10–15 мин)

- [ ] Выбрать **один** повторяемый skill (свой или из библиотеки) под задачу недели.  
- [ ] Запустить на **одном** рабочем артефакте (brief, memo, ICP-кусок).  
- [ ] Ручная правка ≥1 факта + строка в evals-lite: что принять / что отклонить.  
- [ ] Если skill не сработал — одна правка в `SKILL.md`, не новый skill «с нуля».

### 3. Одна SUL-гигиена (≈10–15 мин)

Выберите **один** пункт:

- [ ] Обновить статус вехи в `sul/README.md`, или  
- [ ] Добавить/поправить **1 персону** (без раздувания банка), или  
- [ ] Пометить гипотезу `retired` / `next-live-test`, или  
- [ ] Дописать 1 пункт в `WHERE-IT-LIES` / calibration debt, или  
- [ ] Проверить, что `SYNTHETIC-DATA-NOTICE` на месте в публичных артефактах.

## Раз в месяц (опционально, +30 мин)

- [ ] Сверить один претест/симуляцию с **живым** сигналом (АБ, интервью, support) — или явно продлить calibration debt.  
- [ ] Выкинуть неиспользуемые skills / мёртвые n8n nodes.  
- [ ] Обновить ONEPAGER: что реально автоматизируется на работе.

## Анти-паттерны

- Новый skill каждый понедельник без eval.  
- Digest «для галочки» без чтения выхода.  
- Копировать данные Ритма / чужие персоны как «свой прод».  
- Считать SUL заменой launch-теста.
