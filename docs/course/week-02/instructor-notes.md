# Н2 · Instructor notes — демо ICP на Ритме

## Цель демо (~30–35 мин)

Показать **эталон структуры** ICP + 3 сегмента + 2 персоны на Ритме. Студенты копируют каркас, не копируют сегменты «habit-starters» в свой продукт.

---

## Prep

- [ ] `ritm-sul-demo/product/ONEPAGER.md` (habit / paywall).  
- [ ] Черновик `research/icp-ritm.md`: ICP = фрилансеры 25–35 с Habit-pain; анти-ICP = корпоративный wellness.  
- [ ] 3 сегмента: habit-starters-freelance · relapse-parents · productivity-maxers.  
- [ ] Готовые `P01`, `P02` по схеме (можно из [`../sul/personas/examples/`](../sul/personas/examples/persona-example.md)).  
- [ ] Слайд: «средний пользователь» → красный крест.  
- [ ] Пустой шаблон `competitors.md` на экране.

---

## Скрипт A — ICP (12 мин)

1. Открыть 1-pager Ритма → выписать JTBD вслух.  
2. Заполнить ICP: кто / не кто / канал / WTP-proxy («≤300 ₽/мес»).  
3. Спросить класс: «кого выкинули?» — зафиксировать анти-ICP.  
4. Фраза: «без анти-ICP банк персон раздуется до среднего пользователя».

## Скрипт B — Персоны (12 мин)

1. Показать schema обязательные поля.  
2. Live: вторая персона из сегмента relapse-parents (не читать с листа — диктовать агенту в harness).  
3. Нарочно сделать плохую персону («Мария хочет эффективность») → прогнать QA skill / чеклист.  
4. Underscore: `source: llm_draft` alone = weak.

## Скрипт C — Конкуренты (8 мин)

1. Прямые: другие habit apps.  
2. Заменитель №1: «ничего / календарь / подруга в чате».  
3. УТП-гипотеза одной строкой + 1 falsifier.  
4. Домашка: то же на **своём** продукте; ≥10 персон к сдаче.

---

## Типичные сбои

| Симптом | Реакция |
|---|---|
| 10 персон = один сегмент с разными именами | Вернуть к ≥3 сегментам; сегмент = разный JTBD/constraint |
| Конкуренты = Apple и Google | Сузить до JTBD-overlap |
| Студент копирует Аню из примера в свой B2B SaaS | Запретить; пример только структура |
| Нет sources.md | Не принимать research pack |
