# Н0 · Instructor notes — демо Ритм

## Цель демо (15–20 мин)

Показать студентам **эталон стенда**, не заменить их продукт: «вот как выглядит учебный продукт с данными; ваш кейс может быть тоньше — зато свой».

Стенд: `product-analytics-ai-course` → `docs/stand/` (Postgres + Metabase).  
Студенческий вход: `docs/student-getting-started.md` того же репо.

---

## Скрипт тура

1. **Контекст продукта (3 мин).** Ритм = B2C-привычки, freemium → Pro. На прошлых курсах студенты считали метрики и АБ; здесь Ритм — демо harness/n8n/SUL.  
2. **Показать файловый контур (5 мин).** Открыть в Cursor/Claude Code папку стенда или `PRODUCT_CONTEXT` / словарь — «агент читает репо, не фантазирует схему».  
3. **Показать данные (5 мин).** Metabase или `psql`: `users` / `events` counts. Подчеркнуть: студентам **не** обязательно поднимать Ритм; им нужен свой URL/офер.  
4. **Договор AI (3 мин).** Один слайд из М0.2: AI ≠ вывод. Показать правдоподобную ложь («конверсия без окна»).  
5. **Что сдать на Н0 (2 мин).** Env + 1-pager + договор. Назвать анти-примеры 1-pager.

## Типичные сбои студентов

| Симптом | Что сделать |
|---|---|
| «Нет своего продукта» | Дать шаблон рабочего кейса: приоритизация бэклога, онбординг B2B, лендинг тарифа, исследование сегмента текущего работодателя |
| Docker/n8n не встаёт | Переключить на n8n Cloud; не блокировать Н0 |
| Выбрали Cursor и Claude Code сразу | Ок, но приёмка fluency — по **одному** до зелёного |
| 1-pager про «AI в общем» | Вернуть: нужен объект SUL (экран/офер/процесс) |

---

## Чего не показывать

- Private cloud shares (Mail.ru / Яндекс) — ops only.  
- Пароли и ключи LLM в чате потока.  
- Пиратские архивы / готовые «агентные фермы» из дампов.
