## Что выглядит хорошо (quality bar)

| Артефакт | Структура | Качество |
|---|---|---|
| `hello.md` | 3+ строк, имя продукта, сегмент/JTBD намёк | На диске, не только в чате |
| `verify.md` | хорошо / соврал / как поймал | Есть ≥1 конкретная правка факта |
| `ONEPAGER.md` | все блоки шаблона | Есть **объект** для SUL (URL/экран/офер/процесс); критерий успеха измерим артефактом |
| `ai-contract.md` | 3 секции | ≥3 красных флага; явная граница «AI ≠ вывод» |
| n8n | скрин или export | Инстанс идентифицируем (local/cloud) |

**Отлично:** 1-pager уже намекает 2–3 направления автоматизации и данные/дыры.  
**Достаточно:** объект есть, даже если «только лендинг + desk research».  
**Недостаточно:** «хочу разобраться в AI» без продукта.

## Частые провалы

| Симптом | Что сказать студенту |
|---|---|
| Нет своего продукта | Дать шаблон рабочего кейса (внутренний процесс / лендинг тарифа) |
| 1-pager = рерайт «что такое AI для PM» | Вернуть: нужен объект SUL |
| hello только в чате | «Файл на диске — критерий приёмки» |
| Docker/n8n не поднялся | Cloud trial ok; зафиксировать URL |
| Скопирован Ритм как кейс | Ритм = демо instructor; выбрать свой |
| Ключи в README | Удалить, `.env` / credentials UI |
