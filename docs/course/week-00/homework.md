# Н0 · Домашнее задание — онбординг env + свой продукт

**Срок:** до первого живого занятия (async).  
**Оценка часов:** **2–3 ч** (если env уже стоит — ближе к 1,5 ч).  
**Связанные файлы:** [`student-brief.md`](./student-brief.md) · [`checklist.md`](./checklist.md) · [`lecture.md`](./lecture.md)  
**SUL:** на Н0 веха ещё не стартует; объект продукта должен быть готов к S0 на Н1 ([`../sul/`](../sul/)).

---

## Зачем

Поднять harness + n8n и зафиксировать **свой** продукт/кейс — без этого SUL на Н1–Н8 некуда вешать.

---

## Задачи

### 1. Harness ≥1 (≈45–60 мин)

1. Установите **Cursor** *или* **Claude Code** (второе — опционально).  
2. В пустой/новой папке курса попросите агента создать `notes/hello.md` (3 строки про ваш продукт).  
3. Откройте файл, исправьте ≥1 фактическую ошибку агента.  
4. Запишите в `notes/verify.md`: что хорошо / что соврал / как поймали.

### 2. n8n жив (≈30–45 мин)

1. Поднимите **Docker local** (предпочтительно) или **n8n Cloud**.  
2. Создайте и сохраните хотя бы **пустой** workflow.  
3. Сделайте скрин «Workflows» *или* export JSON пустого flow → `runs/n8n/n0-empty-workflow.json` (без секретов).

Ориентиры: [Choose how to use n8n](https://docs.n8n.io/choose-how-to-use-n8n/) · [Docker install](https://docs.n8n.io/hosting/installation/docker/).

### 3. 1-pager продукта (≈45–60 мин)

Заполните `product/ONEPAGER.md` по шаблону из [`student-brief.md`](./student-brief.md):

| Блок | Минимум |
|---|---|
| Для кого | 1–2 сегмента |
| JTBD | одна фраза |
| Объект | URL / экран / офер / внутренний процесс |
| Автоматизация за 8 нед. | 2–3 направления |
| Данные | честно, в т.ч. «нет» |
| Ограничения | NDA / нет прод / только идея |
| Критерий успеха курса | конкретный артефакт через 8 недель |

### 4. Договор с AI (≈15–20 мин)

`notes/ai-contract.md`: где AI готовит черновик; что подписываете лично; **≥3** красных флага приёмки.
