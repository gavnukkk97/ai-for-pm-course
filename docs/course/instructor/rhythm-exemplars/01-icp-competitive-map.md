## ICP

| Поле | Значение |
|---|---|
| Кто | 25–40, уже пробовали трекер/челлендж и бросили на неделе 1–2; нужен short-series retention, не каталог из 50 привычек |
| Не кто (анти-ICP) | школьники; корпоративный wellness на 10k мест; люди без смартфона как primary channel |
| Каналы | Instagram / word-of-mouth / Product Hunt RU / поиск «привычка без стыда» |
| WTP-proxy | ≤ **300 ₽/мес** на подписки «для себя»; год — если доказан streak ≥7 |
| Job stories (сжато) | J1: один маленький win в развалившийся день · J2: серия без перфекционизма · J3: снять freemium-лимит, не споткнувшись о paywall |

**Фраза для класса:** без анти-ICP банк персон раздуется до «среднего пользователя».

## Карта конкурентов / заменителей

| Тип | Игроки | Overlap JTBD | Чем бьём / проигрываем |
|---|---|---|---|
| Прямые | Streaks, Fabulous, Habitica | серия / геймификация | Ритм проще; слабее «игра» и соцсеть |
| Заменитель №1 | Notes / календарь / «просто пропущу» | J1 маленький win | Нулевой friction у Notes — наш paywall это чувствует |
| Заменитель №2 | чат с другом / accountability | J2 без перфекционизма | Соцдавление > приложение; мы не копируем чат |
| Косвенные | Excel / Notion-шаблоны | J3 система лимитов | Гибкость vs скорость первого check-in |

**УТП-гипотеза (одна строка):** «короткая серия без стыда за срыв + снятие лимита 3 привычки/напоминания, когда depth уже есть».  
**Falsifier:** если depth≥3 не растёт при упрощении онбординга — УТП про «без стыда» не работает, чиним value до paywall.
