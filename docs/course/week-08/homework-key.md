## Что выглядит хорошо

| Артефакт | Структура | Quality bar |
|---|---|---|
| SUL README | статусы S0–S5 | Артефакты согласованы (H__ ↔ REPORT ↔ ставки) |
| CALIBRATION | эталон или debt | Честный «нет данных» > фальшивая калибровка |
| WHERE-IT-LIES | ≥5 пунктов | Конкретные смещения (персона, канал, WTP), не «LLM врёт» |
| Talk-track | 5–7 мин | Вердикт + границы + ask; не тур по Cursor |
| Обязательный абзац | 3 предложения | Заполнен дословно по шаблону рубрики |
| Peer | заполнен соседом | Расхождение >8 обсуждено |

**Отлично:** inconclusive намеренно с сильным живым шагом; WHERE-IT-LIES бьёт в домен.  
**Достаточно:** S0–S4 на месте; рубрика ≥ порога курса (см. ниже); абзац есть.  
**Недостаточно:** демо инструментов; нет S4; прокрас без смещений.

## Частые провалы / auto-fail S5 claim

| Симптом | Действие |
|---|---|
| Ship/kill при «0» внешней валидности | Auto-fail claim; вернуть на абзац границ |
| Нет REPORT S4 | Не принимать защиту |
| Нет WHERE-IT-LIES | Rework |
| Чужой продукт / копия Ритма | Auto-fail |
| Self vs peer >8 без обсуждения | Запросить на защите |
| Только слайды, репо пустое | Fail процессный блок D |
