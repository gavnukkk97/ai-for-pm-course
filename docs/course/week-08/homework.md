## Зачем

Собрать SUL v1 end-to-end, честно защитить: что решили бы / чего недостаточно / следующий живой шаг. **Честность > прокрас.**

---

## Задачи

### A. SUL v1 checklist (≈60–90 мин)

| Веха | Доказательство в репо |
|---|---|
| S0 | README, notice, harness + n8n #1 |
| S1 | ≥15 персон, ≥3 сегмента |
| S2 | 5–7 гипотез + runner plan |
| S3 | sizing + tornado |
| S4 | pretest N≥50 + REPORT |
| S5 | defense pack (ниже) |

Обновите `sul/README.md`: статус каждой вехи.

### B. Калибровка (≈45–60 мин)

`defense/CALIBRATION.md`:

1. Эталон сравнения (свой прошлый АБ / публичный кейс / «нет данных»).  
2. Ожидаемый знак vs факт (если есть).  
3. Что меняет в доверии к S4.  
4. Если данных нет — **calibration debt**: какой живой тест закроет долг.

### C. Пакет защиты (≈90–120 мин)

`defense/`:

| Файл | Содержание |
|---|---|
| `TALK-TRACK.md` | 5–7 мин устной защиты |
| `SLIDES.md` или PDF | визуал; **обязателен** слайд границ §3.4 |
| `RUBRIC-SELF.md` | самооценка по [`s5-defense-rubric.md`](../sul/templates/s5-defense-rubric.md) |
| `PEER.md` | лист соседа (на занятии / заранее) |
| `WHERE-IT-LIES.md` | ≥5 пунктов «где врёт симуляция» |

Обязательный абзац (без него S5 не закрыт):

> По симуляции мы бы: …  
> Этого недостаточно, чтобы: …  
> Следующий живой шаг: …

### D. Peer-review (на занятии / −24 ч)

1. Обмен репо.  
2. Баллы только по наблюдаемым артефактам.  
3. Расхождение self vs peer > 8 баллов — обсудить на защите.

### E. Чтение

Полная рубрика S5 · AgentA/B + SimAB · свой REPORT S4.
