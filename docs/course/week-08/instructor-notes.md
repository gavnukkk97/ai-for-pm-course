# Н8 · Instructor notes — эталонная защита на Ритме

## Цель демо + фасилитация (~90 мин занятия)

Показать **образцово честную** защиту Ритма (включая провал/inconclusive), затем провести ротацию студенческих защит.

---

## Prep

- [ ] Эталонный talk-track Ритма на 6 мин с слайдом «где врёт».  
- [ ] Заполненная рубрика на Ритм (не идеальные 39/39 — реалистично 24–30).  
- [ ] Таймер 7+3.  
- [ ] Peer-листы распечатаны / в shared doc.  
- [ ] Список красных флагов на слайде.

---

## Скрипт A — Эталон (15 мин)

1. Пройти S0→S5 одной дугой.  
2. Назвать вердикт inconclusive по одному из тестов — **намеренно**.  
3. Показать, как это повышает, а не снижает оценку.  
4. Калибровка: «знак совпал с прошлым маленьким АБ / не совпал».

## Скрипт B — Защиты (основное время)

1. Очередь; строгое время.  
2. Вопросы только: метрика, N, validity, живой шаг.  
3. Стоп-слово при ship/kill без оговорок — попросить переформулировать.

## Скрипт C — Peer + закрытие (15 мин)

1. Обмен PEER.md.  
2. Три паттерна класса (что все делают хорошо / плохо).  
3. Next: перенос harness+n8n на работу; живой АБ.

---

## Типичные сбои

| Симптом | Реакция |
|---|---|
| Демо инструментов вместо решения | Срезать; вернуть к абзацу вердикта |
| Нет WHERE-IT-LIES | Не ставить зачёт S5 |
| Peer ставит баллы «за старание» | Напомнить: только артефакты |
| Репо без S4 логов | S5 не принимается |

---

## Оценка

Ориентир: сумма рубрики + обязательный проход красных флагов (см. s5-defense-rubric). Честность > прокрас — явный критерий в программе.
