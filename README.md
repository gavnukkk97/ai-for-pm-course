# AI для продакта

Публичный студенческий пакет курса. Фокус — **AI-контур продакта** (harness + n8n) и флагман **Synthetic User Lab** на своём продукте. Демо преподавателей — на стенде **Ритм** из [`product-analytics-ai-course`](https://github.com/gavnukkk97/product-analytics-ai-course).

## Быстрый старт

1. Программа (утверждённая сетка 8 недель + SUL): [`docs/program.md`](docs/program.md).
2. Карта материалов: [`docs/course/README.md`](docs/course/README.md).
3. Неделя 0 (онбординг): [`docs/course/week-00/`](docs/course/week-00/).
4. Неделя 1 (AI-экзоскелет + S0): [`docs/course/week-01/`](docs/course/week-01/).
5. Scaffold SUL: [`docs/course/sul/`](docs/course/sul/).
6. Reading list: [`docs/external-materials.md`](docs/external-materials.md) и [`docs/course/materials-by-module.md`](docs/course/materials-by-module.md).
